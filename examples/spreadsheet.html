Quarterly Sales by Rep

A plain rendered <table> — the kind of thing a "corporate app" shows and an LLM would otherwise try to add up in its head (and get wrong). Point ml.pythonExec at it with { tables: "#sales" } and it lands in the sandbox as a pandas df for exact math.

Try:

await ml.agent("What's the grand total of all quarters, the top rep by annual total, and the highest-grossing region? Use python_exec on the #sales table — don't eyeball it.", { extraTools: [ml.pythonTool()] })

😈 Ridiculous mode

A big table (40 reps × 12 months) in a box that scrolls both ways — you can't see it all at once, so eyeballing/transcribing every cell is hopeless. It also has dirty cells: blanks, N/A, a comma 1,250, currency $300, an accounting negative (180), and a typo 12O0 (letter O). The only sane path is python_exec({ tables: "#bigsales" }) — the auto-cast coerces the formatted cells and turns the junk into NaN, and pandas skips those in .sum().

Try: await ml.agent("Grand total of ALL months across ALL reps (ignore bad/missing cells), and the top region by total. Use python_exec on #bigsales — the table scrolls, don't try to read it.", { extraTools: [ml.pythonTool()] })

Scrolls vertically (40 rows) and horizontally (15 columns). The answer is in the devtools console when you open this, and in an HTML comment above.
