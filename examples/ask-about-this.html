Right-click scoping demo

A 1-pixel click lands on a deep leaf node (an avatar, a timestamp, a like count). Sending that to a model is useless. The right-click resolver climbs to the SEMANTIC UNIT around it — the whole tweet, comment, or card — and sends clean text + a scope selector, not a screenshot or raw HTML.

Try it: right-click ANY deep leaf below → "Ask window.ml about this". The Commander opens with a 📌 pill naming the container it resolved (not the leaf). Hover the pill to see that container boxed on this page — so you know exactly what context is captured before you send.
(Needs the window.ml extension loaded, with the HUD available. Then type a question like "how dumb is this post?" and Send.)
