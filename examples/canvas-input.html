Canvas Input — remote-desktop / game mock

A bare <canvas> that behaves like a WebGL game, a 2D canvas app, or a streamed remote desktop: it has no DOM text (nothing for findByText to read) and — like real games — it only honours TRUSTED input. It draws every isTrusted key/click it receives onto its own surface and ignores synthetic ones (counting them in the corner). So the only way to confirm input landed is to look at the pixels, and the only way to make it land is a trusted (CDP) event.

Try (turn ON "Debugger-based actions (CDP)" in window.ml Settings → Advanced first):

await ml.agent("Click the black screen, type the word HELLO, then press Enter. Confirm by looking that HELLO appears on the screen.", { extraTools: [ml.clickTool(), ml.typeTool(), ml.lookTool(), ml.locateTool()] })

Inside a run the agent uses type with a special target: { selector: "@focus", text: "HELLO", submit: true } types into the currently-focused screen, or it locates a spot and types into the @pt it gets back (which clicks to focus first). With CDP OFF the events are synthetic, so this screen ignores them (the "ignored" counter ticks up) — that's the whole point of the trusted path.
