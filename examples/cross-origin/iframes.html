Iframes — same-origin vs cross-origin

An <iframe> is a separate document. The agent's DOM tools don't cross frames, and a synthetic click on the <iframe> element doesn't hit-test inside — so a control in a frame is a "reserved" surface: the only way to click it is a real, hit-tested debugger (CDP) click (turn on "reserved-element clicking" in window.ml Settings → Advanced). The two panels below differ in one thing — whether the frame is same- or cross-origin — which changes only whether the approval shows the privileged-click warning.

How to run it (needs a local server)

A genuinely cross-origin iframe needs two real HTTP origins — file:// won't do. A tiny dependency-free server serves this page + the same-origin frame on one port, and the cross-origin frame on another (different ports = different origins under the Same-Origin Policy):

node examples/cross-origin/serve.mjs
# → open  http://localhost:8080  in a tab where window.ml is active  (NOT file://)

If the panels below are blank, you opened this as a file:// path — start the server and open http://localhost:8080 instead.

Challenge 1 — a same-origin iframe no warning

Served from the same origin as this page. Its contentDocument is reachable by page JS, but the agent's DOM tools still don't cross frames and a synthetic click can't reach in — so the click routes through CDP all the same. Because it's same-origin, the approval shows no privileged-click warning (no security boundary is being crossed).

await ml.agent("Reveal and read the secret in the FIRST (same-origin) panel.")

Challenge 2 — a cross-origin iframe ⚠ warning

Served from a different origin (a different port). The Same-Origin Policy walls it off from this page and the agent's DOM tools; a synthetic click can't cross it; and the secret is hidden until the button inside is clicked, so vision can't read it. Only a CDP click reaches it — and because it's cross-origin, the approval shows a red privileged-click warning naming the frame's origin. This is the exact case that warning exists for (it reaches into embedded third-party content using your session there).

await ml.agent("Reveal and read the secret in the SECOND (cross-origin) panel.")
