An empty page for an agent to start on

A run asked for a new tab rather than one of yours, and a browser extension cannot run on the browser's own new-tab page — so it opens this one instead: an ordinary web page, with nothing on it and nothing to read.

The run's first move is normally to go somewhere real. If you are reading this and no run is going, nothing is wrong; you have simply opened a page that exists to be left.

You can point runs at a page of your own instead — Settings → Agent start page in the extension.
